# Security Policy

## Supported versions

The latest released version receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately rather than opening a public issue.

Use GitHub's **Report a vulnerability** button on the Security tab of this
repository, which opens a private advisory visible only to maintainers.

Please include a description of the issue, steps to reproduce, and the affected
version. We aim to acknowledge reports within a few business days and will keep
you updated on progress toward a fix.
